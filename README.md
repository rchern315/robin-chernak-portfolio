# Robin Chernak — Portfolio

Personal engineering portfolio for Robin Chernak, Full-Stack Software Engineer.

## Focus

- Full-stack engineering
- Platform engineering
- AI-enabled applications
- Automation
- DevOps
- Data and integrations

## Built with

- Next.js 16
- React 19
- TypeScript
- CSS
- Vercel-ready deployment

## Local development

Clone the repo, run npm install, then npm run dev.

## Engineering Notes

The portfolio includes a lightweight engineering-notes section built directly into the Next.js app. No CMS or database is required for the initial version.

## Deployment

Import this repository into Vercel. The default Next.js build settings are sufficient.
